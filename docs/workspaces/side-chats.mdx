---
title: Side Chats
description: Ask a quick side question without derailing the main chat
---

Use `/side` (or its alias `/btw`) to ask a side question in a temporary copy of the current chat. The side chat knows everything the main chat knows, but nothing you say in it is added to the main chat.

```
/side [question]
```

With a question, the side chat opens and sends it right away. Without one, it opens empty so you can type.

## How side chats work

- **Inherits context**: the side chat starts from the main chat's conversation, including a turn that is still streaming, and uses the same model and settings.
- **Main chat keeps going**: an agent working in the main chat continues in the background. The side chat header shows whether the main chat is working or idle.
- **Same checkout**: the side chat runs in the main chat's working tree, so it sees uncommitted changes.
- **Understanding, not changes**: side chats are for interactive questions and explanations. The agent is instructed not to edit files or run commands that would interfere with the main chat. Make changes from the main chat instead.
- **Temporary**: press <kbd>Esc</kbd> (or <kbd>Ctrl+C</kbd> in Vim mode) when the side chat is idle, or click **Return to main chat**, to go back. The side chat is discarded when you leave it, however you leave, and it does not appear in the sidebar. While the side chat is answering, the first press interrupts it and the next one returns.
- **One at a time**: starting a new side chat discards the previous one for that workspace. Side chats can't be nested, and workspace commands such as `/fork`, `/compact` and `/goal` are not available inside them.

Side chats are available for local, worktree and SSH workspaces.

<Tip>
  To keep exploring a tangent for longer, or to make changes on it, use [`/fork`](/workspaces/fork)
  instead: a fork is a full workspace with its own branch.
</Tip>
