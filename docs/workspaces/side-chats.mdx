title: Side Chats
description: Ask a quick side question without derailing the main chat
---

Use `/side` (or its alias `/btw`) to ask a side question in a temporary copy of the current chat. The side chat opens as a **Side chat** tab in the right sidebar, so you can follow it and the main chat at the same time. The side chat knows everything the main chat knows, but nothing you say in it is added to the main chat.

```
/side
```

The command takes no arguments. It opens an empty composer; type your question in the side chat.

## How side chats work

- **Inherits context**: the side chat starts from the main chat's conversation, including a turn that is still streaming, and uses the same model and settings.
- **Main chat keeps going**: an agent working in the main chat keeps working next to the side chat. Keyboard shortcuts such as <kbd>Esc</kbd> to interrupt apply to whichever chat has focus.
- **Same checkout**: the side chat runs in the main chat's working tree, so it sees uncommitted changes.
- **Understanding, not changes**: side chats are for interactive questions and explanations. Only read-only inspection tools are available: no shell, file edits, workflows, sub-agents, or project-defined tools can change the shared checkout. Make changes from the main chat instead.
- **Attachments**: add files in the main chat before opening a side chat, or ask the side chat to read an existing local file. New attachment uploads in side chats are disabled so they cannot leave files behind in the shared checkout.
- **Disposable**: closing the tab (its close button, middle-click, or <kbd>Ctrl+W</kbd> / <kbd>Cmd+W</kbd> while it is focused) discards that side chat. Removing or archiving the main workspace discards its side chats too. Open side-chat tabs survive app restarts and stay out of the workspace list.
- **Multiple conversations**: run `/side` again in the main chat to open another independent tab. Closing one leaves the others intact. Side chats can't be nested, and workspace commands such as `/fork`, `/compact` and `/goal` are not available inside them.

When the right sidebar is hidden (narrow windows and phones), the side chat takes over the chat view instead. Press <kbd>Esc</kbd> (or <kbd>Ctrl+C</kbd> in Vim mode) when it is idle, or click **Return to main chat**, to go back; leaving discards it.

Side chats are available for local, worktree and SSH workspaces.

<Tip>
  To keep exploring a tangent for longer, or to make changes on it, use [`/fork`](/workspaces/fork)
  instead: a fork is a full workspace with its own branch.
</Tip>
